## Tareas detalladas

### 7.1 — Schema Drizzle: `auditoria`

Crear `src/db/schema/auditoria.schema.ts` según diseño DBML:

```ts
Table auditoria {
  id uuid PK (default gen_random_uuid())
  tabla varchar(60) not null
  registro_id text not null
  accion varchar(20) not null   // 'crear' | 'editar' | 'eliminar'
  antes jsonb                   // null en crear
  despues jsonb                 // null en eliminar
  realizado_por text not null   // user_id FK → user.id
  ip_address text
  created_at timestamp not null (default now())
}
```

- Exportar en `src/db/index.ts`
- Generar migración Drizzle: `npx drizzle-kit generate`
- Ejecutar migración: `npx drizzle-kit migrate`

**Archivos a crear/modificar:**
- `src/db/schema/auditoria.schema.ts` (nuevo)
- `src/db/index.ts` (añadir export)
