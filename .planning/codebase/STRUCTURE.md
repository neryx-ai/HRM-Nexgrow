## Directory Purposes

**`src/app/`:**
- Purpose: Next.js App Router — all routes, layouts, and pages
- Contains: `page.tsx` files (route handlers), `layout.tsx` files (shared layout shells), route groups `(auth)`, API routes
- Key files: `src/app/layout.tsx` (root), `src/app/page.tsx` (redirector), `src/app/dashboard/layout.tsx` (sidebar shell)

**`src/app/(auth)/`:**
- Purpose: Authentication pages (login, register, password recovery)
- Contains: One subdirectory per auth page with `page.tsx` and co-located form component
- Key files: `src/app/(auth)/login/login-form.tsx`, `src/app/(auth)/register/register-form.tsx`

**`src/app/dashboard/`:**
- Purpose: Protected application pages behind auth
- Contains: Dashboard home, profile, and catch-all slug for unimplemented routes
- Key files: `src/app/dashboard/profile/page.tsx`, `src/app/dashboard/[...slug]/page.tsx`

**`src/actions/`:**
- Purpose: Server Actions — server-side functions callable from client components
- Contains: `"use server"` exported async functions with `ActionResponse` return type
- Key files: `src/actions/auth.actions.ts` (login, logout, profile CRUD, password change), `src/actions/types.ts`

**`src/components/modules/`:**
- Purpose: Feature-specific client components (forms, complex UI blocks)
- Contains: One subdirectory per feature with its form/component
- Key files: `src/components/modules/profile/profile-form.tsx`

**`src/components/navigation/`:**
- Purpose: App shell navigation (sidebar, navbar, triggers)
- Contains: Client components that read auth session for conditional rendering
- Key files: `src/components/navigation/sidebar.tsx`, `src/components/navigation/navbar.tsx`

**`src/components/ui/`:**
- Purpose: shadcn/ui generated primitives
- Contains: Button, Card, Input, Sidebar, Sheet, Avatar, Dropdown, Tooltip, etc.
- Key files: All files are auto-generated by `npx shadcn add <component>` — DO NOT edit manually

**`src/components/theme/`:**
- Purpose: Theme switching infrastructure
- Contains: ThemeProvider wrapper and ModeToggle dropdown
- Key files: `src/components/theme/theme-provider.tsx`, `src/components/theme/mode-toggle.tsx`

**`src/db/`:**
- Purpose: Database layer — connection, schema definitions, barrel exports
- Contains: Drizzle ORM schema files, connection setup, re-exports
- Key files: `src/db/drizzle.ts` (connection), `src/db/schema/auth.schema.ts` (tables), `src/db/index.ts` (barrel)

**`src/lib/`:**
- Purpose: Shared utilities, auth configuration, validation schemas
- Contains: Auth server/client instances, RBAC permissions, Valibot schemas, utility functions
- Key files: `src/lib/auth.ts`, `src/lib/auth-client.ts`, `src/lib/permissions.ts`, `src/lib/utils.ts`

**`src/lib/validations/`:**
- Purpose: Input validation schemas with Valibot
- Contains: `.ts` files exporting Valibot schemas and inferred types
- Key files: `src/lib/validations/auth.ts`

**`src/types/`:**
- Purpose: Shared TypeScript type definitions
- Contains: Role types and role constant maps
- Key files: `src/types/roles.ts`

**`src/hooks/`:**
- Purpose: Custom React hooks
- Contains: Utility hooks for responsive behavior
- Key files: `src/hooks/use-mobile.ts`

## Key File Locations

**Entry Points:**
- `src/app/layout.tsx`: Root HTML layout (ThemeProvider, Toaster, TooltipProvider)
- `src/app/page.tsx`: Root route — session check → redirect to `/dashboard` or `/login`
- `src/app/api/auth/[...all]/route.ts`: Better Auth API handler

**Configuration:**
- `next.config.ts`: Next.js config (currently empty)
- `drizzle.config.ts`: Drizzle Kit — schema at `./src/db/index.ts`, migrations to `./migrations/`, PostgreSQL dialect
- `components.json`: shadcn/ui config — new-york style, Geist fonts, stone base color, `@/*` aliases
- `tsconfig.json`: TypeScript — strict mode, `@/*` → `./src/*` path alias, bundler module resolution
- `postcss.config.mjs`: PostCSS with `@tailwindcss/postcss` plugin (Tailwind v4)

**Core Logic:**
- `src/lib/auth.ts`: Better Auth server instance (Drizzle adapter, admin plugin, RBAC roles)
- `src/lib/auth-client.ts`: Better Auth React client (admin plugin for permission checks)
- `src/lib/permissions.ts`: Access control — resources, actions, role definitions (admin, rrhh, empleado)
- `src/actions/auth.actions.ts`: All auth-related Server Actions
- `src/proxy.ts`: Route protection logic (public paths, session check, role-based redirects)

**Database:**
- `src/db/drizzle.ts`: PostgreSQL connection via `pg.Pool` + Drizzle ORM
- `src/db/schema/auth.schema.ts`: Tables — `user`, `session`, `account`, `verification` + relations
- `src/db/index.ts`: Barrel re-export of all schema exports

**Testing:**
- No test files or test configuration detected

## Naming Conventions

**Files:**
- Pages: `page.tsx` (Next.js App Router convention)
- Layouts: `layout.tsx` (Next.js App Router convention)
- Client form components: `kebab-form.tsx` (e.g., `login-form.tsx`, `register-form.tsx`, `recovery-form.tsx`)
- Feature module components: `kebab-form.tsx` (e.g., `profile-form.tsx`)
- Schema files: `kebab.schema.ts` (e.g., `auth.schema.ts`)
- Validation files: `kebab.ts` (e.g., `auth.ts`)
- Action files: `kebab.actions.ts` (e.g., `auth.actions.ts`)
- UI primitives: `kebab.tsx` (e.g., `button.tsx`, `dropdown-menu.tsx`)
- Navigation components: `kebab.tsx` (e.g., `sidebar.tsx`, `navbar.tsx`)
- Type files: `kebab.ts` (e.g., `roles.ts`)
- Hook files: `use-kebab.ts` (e.g., `use-mobile.ts`)

**Directories:**
- Route groups: `(kebab)` (e.g., `(auth)`)
- Feature modules: `kebab` (e.g., `profile`)
- Schema directories: `kebab` (e.g., `schema`)
- Component categories: `kebab` (e.g., `navigation`, `theme`, `ui`, `modules`)

**Exports:**
- Pages: `export default function PageName()` (Next.js convention)
- Layouts: `export default function LayoutName()`
- Server Actions: named `export async function` with `"use server"` directive at file top
- Components: named `export function ComponentName()` or `export default function ComponentName()`
- Barrel exports: `export * from "./path"` in `index.ts` files

## Where to Add New Code

**New Dashboard Page (e.g., "Employees"):**
- Page: `src/app/dashboard/employees/page.tsx` (RSC page, fetches data)
- Form component: `src/components/modules/employees/employees-form.tsx` (client component)
- Server Actions: `src/actions/employees.actions.ts` (CRUD operations)
- Validation: `src/lib/validations/employees.ts` (Valibot schemas)
- Schema: `src/db/schema/employees.schema.ts` (Drizzle tables)
- Update barrel: `src/db/index.ts` (add re-export)

**New Navigation Menu Item:**
- Edit: `src/components/navigation/sidebar.tsx` (add permission check + SidebarMenuItem)
- Edit: `src/components/navigation/navbar.tsx` (add pathLabel case)

**New UI Component:**
- Run: `npx shadcn@latest add <component>` — generates into `src/components/ui/`
- DO NOT manually create files in `src/components/ui/`

**New Validation Schema:**
- Create: `src/lib/validations/<domain>.ts`
- Pattern: Import `* as v from "valibot"`, export schema + `v.InferOutput<>` type

**New Database Table:**
- Create: `src/db/schema/<domain>.schema.ts`
- Update: `src/db/index.ts` to re-export
- Generate migration: `npx drizzle-kit generate`
- Run migration: `npx drizzle-kit migrate`

**New Role or Permission:**
- Edit: `src/lib/permissions.ts` (add to statement + role definitions)
- Edit: `src/lib/auth.ts` (if adding new role to Better Auth config)
- Edit: `src/lib/auth-client.ts` (if adding new role to client config)
